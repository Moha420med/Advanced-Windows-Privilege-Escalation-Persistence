# Advanced Windows Privilege Escalation and Persistence for Red Teamers

Welcome to the official repository for the **Advanced Windows Privilege Escalation and Persistence for Red Teamers** course by **BugzZone**.

## 🛠️ Repository Contents

This repository contains tools, scripts, and lab resources used throughout the course.

- **Advanced Enumeration:** Windows system, service, permission, and configuration checks.
- **Privilege Escalation:** Resources for identifying and validating potential privilege escalation paths.
- **Persistence Techniques:** Educational scripts and demonstrations of Windows persistence mechanisms.
- **Red Team Utilities:** Supporting tools and custom scripts used in authorized lab exercises.
- **Lab Resources:** Examples and configuration files for reproducing course exercises.

## 📌 Usage

Clone the repository to your local machine for use in an isolated Windows lab or an authorized penetration testing environment.

```bash
git clone https://github.com/Moha420med/Advanced-Windows-Privilege-Escalation-Persistence.git
cd Advanced-Windows-Privilege-Escalation-Persistence
```

Review each tool's documentation before running it.
